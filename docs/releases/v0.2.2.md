# Garmin LiveTrack v0.2.2

## Summary

Map trackers use the Garmin display name by default, with YAML examples for custom names, photos, and icons.

## Changes

- Removed the `Garmin LiveTrack` prefix from per-user device names and made the tracker inherit the device name once.
- Preserved configured user-name spelling before the first session and readable fallback names for unidentified sessions.
- Kept existing entity IDs, device identifiers, and user-supplied name overrides.
- Added [map customization examples](../ADVANCED.md#map-names-pictures-and-icons) for names, photos, fixed icons, and activity icons.
- Updated the integration manifest, package metadata, and default HTTP User-Agent to `0.2.2`.

## Upgrade notes

Restart Home Assistant after updating. Dashboard and automation references continue to use the existing entity IDs.

If an old map label remains, check device, entity, YAML, and map-card name overrides. Clear an override to use the new default; do not recreate entity IDs.

## Validation

- Naming changes: 71 tests passed on Python 3.12.3 with Home Assistant 2025.1.4 in a disposable Linux copy.
- Verified Home Assistant name resolution and parsed all three YAML customization examples.
- Checked version consistency and patch whitespace after the version bump.
