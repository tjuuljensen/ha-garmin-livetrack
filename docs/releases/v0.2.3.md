# Garmin LiveTrack v0.2.3

## Summary

Expose elevation gain when Garmin supplies it, keep the shared activity icon when multiple sessions have the same activity, and update installation instructions for Home Assistant Marketplace.

## Changes

- Added `elevation_gain_m` to per-user status sensors, device trackers, and session/point events. The parser prefers `totalElevationGainMeters`, falls back to `elevationGainMeters`, and accepts older nested fitness data.
- Preserve the last supplied elevation gain across sparse trackpoints and in retained ended-session summaries restored after a restart. Missing gain remains unknown; an explicit zero is preserved.
- Fixed `Any Active` showing the mixed-activity icon when multiple active sessions share the same normalized activity. Mixed activities still use the multiple-marker icon; counts and summaries remain per session.
- Replaced HACS installation instructions with the Marketplace flow introduced in Home Assistant 2026.11. Existing publisher metadata and validation tooling retain their HACS names.
- Removed speculative validation tasks and stale release preparation from the development backlog, retaining concrete behavior and usability issues.
- Updated the integration manifest, package metadata, and default HTTP User-Agent to `0.2.3`.

## Upgrade notes

Restart Home Assistant after updating. Existing entity IDs and automation references remain unchanged.

Elevation gain is an attribute, not a separate sensor, and is distinct from current altitude. Garmin's current frontend supports the gain fields, but the REST response inspected for a reported missing-elevation case contained 284 points without either field. This update cannot supply gain for sessions where Garmin omits it. See the [fetch investigation](../GARMIN_FETCH_STRATEGY.md#elevation-gain-verification).

Use [Marketplace installation](../../README.md#home-assistant-marketplace) on Home Assistant 2026.11 or later. Older Home Assistant installations can use an existing HACS installation or manual installation.

## Regression coverage

The full suite passed with 101 tests in a disposable Linux copy on Python 3.12.3 with Home Assistant 2025.1.4 before the release metadata bump. Coverage includes elevation field precedence, missing and zero values, sparse points, event/entity attributes, saved-summary restoration, and shared-activity icons.
