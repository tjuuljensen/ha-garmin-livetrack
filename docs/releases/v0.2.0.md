# Garmin LiveTrack v0.2.0

Historical notes for `0.2.0`. For the current changes, see [v0.2.1](v0.2.1.md).

## Features

- UI configuration with global settings, configured users, per-user activity filters, and user removal.
- Manual URL submission and automatic ingestion from Home Assistant IMAP events.
- Independent concurrent sessions, stable per-user devices, and global activity/health entities.
- Restart recovery for active sessions and retained summaries of finished sessions.
- Garmin session and incremental trackpoint fetching, with payload and hydration fallbacks.
- Extended, Conservative, Balanced, Adaptive, and Advanced update profiles. Adaptive uses Garmin publishing frequency to gate trackpoint requests.
- Per-session backoff for rate limits, server errors, and retryable request failures.
- Normalized activity names, activity-specific icons, and activity metrics for dashboards and automations.
- Lifecycle and point events for Home Assistant automations. Notification delivery is handled by those automations.
- Configurable HTTP User-Agent, optional debug attributes, diagnostics, and repair signaling for repeated response anomalies.

## Session Presentation

Per-user status sensors retain finished-session summaries across restarts during the retention window. Sparse final points retain earlier altitude, heart rate, power, and cadence when available. Missing duration, distance, and speed can be derived from timestamps and GPS movement.

## Data Exposure

Status-sensor attributes expose full LiveTrack URLs, including access tokens. Session diagnostics use redacted URLs; event payloads omit URLs and tokens but include activity metrics and coordinates. Diagnostics retain user names and policy settings.

## Installation and Known Limitations

See the [README](../../README.md) for installation, configuration, screenshots, and troubleshooting, and the [development backlog](../../TODO.md) for outstanding validation work.
