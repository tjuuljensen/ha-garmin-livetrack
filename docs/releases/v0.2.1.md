# Garmin LiveTrack v0.2.1

## Summary
This patch updates session metadata requests to Garmin LiveTrack API v2 and establishes consistent line endings for cross-platform development.

## Changes
- Session metadata requests use `/api/v2/sessions/{sessionId}?token={token}`.
- Incremental trackpoint requests continue to use `/api/sessions/{sessionId}/track-points/common`.
- The integration manifest, package metadata, and default HTTP User-Agent identify version `0.2.1`.
- `.gitattributes` normalizes source and documentation files to LF and preserves binary assets.
- README and fetch strategy documentation describe the current endpoint behavior.
- Removed the `garmin_livetrack.cleanup_legacy_entities` service, its legacy cleanup implementation, and related tests and documentation. Current session lifecycle cleanup and user entity/device cleanup remain unchanged.
- Shortened the README around installation and everyday use, with screenshots and a clickable contents list.
- Moved detailed configuration, actions, events, troubleshooting, and local testing to [Advanced configuration and reference](../ADVANCED.md).
- Aligned documentation and UI help with current user-policy, event, lifecycle, and privacy behavior.

Garmin LiveTrack remains an undocumented API and may change without notice.

## Upgrade notes
Remove calls to `garmin_livetrack.cleanup_legacy_entities` from existing automations or scripts before upgrading. Any entities left over from older integration versions must be removed manually in Home Assistant.

## Validation
- Merged working tree: 66 tests passed on Python 3.12.3 with Home Assistant 2025.1.4 in a disposable Linux copy.
- Earlier validation recorded 66 passed on Python 3.14 with Home Assistant 2026.10.4.
